# Trendora – Fashion E-Commerce Website

Trendora is a modern fashion e-commerce website designed to provide users with a smooth and interactive online shopping experience.

## Features
- Modern and responsive design
- Product listing
- Product search functionality
- Category-based product filtering
- Add to Cart functionality
- Shopping cart management
- Increase and decrease product quantity
- Newsletter subscription interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` – Website structure
- `styles.css` – Website design and styling
- `script.js` – Website functionality
